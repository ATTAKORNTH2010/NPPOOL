# PrintForm — ตัวอย่างแบบฟอร์มที่สั่งพิมพ์

โฟลเดอร์นี้เก็บ **ตัวอย่างแบบฟอร์ม** ที่ระบบต้องพิมพ์ เพื่อใช้เทียบตอนพัฒนาและตรวจรับ

## กติกา (repo นี้เป็นสาธารณะ)

- ขึ้น GitHub ได้เฉพาะไฟล์นี้ และไฟล์ตัวอย่างที่ **ไม่มีข้อมูลจริง** ซึ่งตั้งชื่อเป็น `*.sample.*` เช่น `job-order.sample.png`
- ไฟล์ตัวอย่างจริงจากงาน (ชื่อลูกค้า ชื่อผู้ติดต่อ เบอร์โทร เลข Job) **เก็บไว้ในเครื่องเท่านั้น** — `.gitignore` กันไม่ให้ไฟล์อื่นในโฟลเดอร์นี้ถูก commit
- ก่อนเพิ่มไฟล์ `*.sample.*` ให้ลบหรือเปลี่ยนข้อมูลจริงเป็นค่าสมมติทุกช่องก่อน

ไฟล์ที่ผู้ใช้ส่งมาเมื่อ 2026-11-27 (อยู่ในเครื่องเท่านั้น ไม่ขึ้น GitHub): ใบสั่งปฏิบัติงานจริง 1 ใบในรูป PNG และ PDF + สมุดงาน Excel ที่ใช้ออกใบสั่งงานอยู่ (ชีต `Step 1`, `Step 2`, `Print`)

## ใบสั่งปฏิบัติงาน (WO-12)

หน้าพิมพ์ในระบบใหม่: `/work-orders/{id}/print` (ADR-0005 ทางเลือก A) จัดหน้าตามตัวอย่างนี้

- A4 แนวนอน · หัวกล่องสีเหลือง `#FFC000` · ช่องที่ไม่มีข้อมูลพิมพ์ “-”
- ชื่อไฟล์ตอน “บันทึกเป็น PDF” = `JobOrder_{เลขที่ใบงาน}`
- รถหลายคัน: ตารางประเภทรถ/พขร/ทะเบียน มีแถวละคัน (อย่างน้อย 5 แถวให้เขียนเพิ่มได้) และตารางจำนวน/น้ำหนัก/ขนาดมีแถวละคัน

### ยังต้องตัดสินใจ

- **ช่องที่ใบงานยังไม่มี:** Ref.No, CS Name, AWB No., เขต/แขวง และจังหวัด ของต้นทาง/ปลายทาง — ตอนนี้พิมพ์ “-” · ถ้าต้องการให้กรอกในใบงาน ต้องเพิ่มช่องในฐานข้อมูลและฟอร์ม
- **โลโก้ (B8):** ตอนนี้ใช้ตัวอักษร “N.P. POOL GROUP” แทน · ต้องการไฟล์โลโก้ หรืออนุญาตให้ใช้ไฟล์โลโก้จากระบบเดิม
- **ปี:** แบบฟอร์ม Excel เดิมพิมพ์ปี ค.ศ. (เช่น 18/9/2025) · ระบบใหม่พิมพ์ปี พ.ศ. ตาม ADR-0008 (26/11/2569)
