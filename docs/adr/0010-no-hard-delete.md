# ADR-0010: ไม่ลบถาวร — ยกเลิกใบงาน / ปิดใช้งานข้อมูลพื้นฐาน

- สถานะ: อนุมัติ (D17 — 2026-11-27)
- วันที่: 2026-11-26

## บริบท

ระบบเดิมลบทุกอย่างแบบถาวร และฐานข้อมูลไม่มี FK → ลบผู้ว่าจ้าง/รถ/คนขับที่ใบงานอ้างอยู่ได้ ชื่อจึงหายจากรายการใบงาน (F12, BR-MD-05) · ใบงานที่ลบแล้วทำให้เลขที่ถูกใช้ซ้ำ (F1)

## ทางเลือก

1. ลบถาวรเหมือนเดิม
2. **ใบงาน: ยกเลิก (สถานะ 2) · ข้อมูลพื้นฐาน: ปิดใช้งาน (`is_active`) · มี FK จริงทุกความสัมพันธ์**
3. soft delete ทุกตาราง (`deleted_at`) — ซับซ้อนกว่าที่ต้องการ

## การตัดสินใจ (เสนอ)

ทางเลือก 2:

- **ใบงาน:** ปุ่ม “ยกเลิกใบงาน” (Maker, Admin) → `status_code = 2` + `cancelled_at`, `cancelled_by` · check constraint ให้สถานะ 2 กับ `cancelled_at` ไปด้วยกันเสมอ · ตอนสร้างใบงานเลือกสถานะ “ยกเลิก” ไม่ได้ · ใน MVP ไม่มีการลบใบงานถาวร
- **ข้อมูลพื้นฐาน:** ปิด/เปิดใช้งาน (Admin) · รายการที่ปิดใช้งานไม่อยู่ใน dropdown ของใบงานใหม่ แต่ใบงานเก่ายังแสดงชื่อ · ลบถาวรได้เฉพาะรายการที่ยังไม่มีใบงานอ้างถึง (FK แบบ restrict กันไว้)
- รถในใบงาน (`work_order_vehicles`) ลบตามใบงานแม่เท่านั้น (cascade)

## ผลที่ตามมา

- หน้าข้อมูลพื้นฐานมีตัวกรอง “แสดงที่ปิดใช้งาน”
- ข้อมูลไม่หายจากการกดผิด และรายงาน/ใบวางบิลในอนาคตเห็นใบงานที่ยกเลิกได้
- เลขที่ใบงานไม่ถูกใช้ซ้ำ (ADR-0007)
