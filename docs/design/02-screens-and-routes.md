## 3. รายละเอียดหน้าจอ

### 3.1 เข้าสู่ระบบ (`/login`)

- โลโก้ NP Pool + ชื่อระบบ “NP Pool รับขนส่งสินค้าทั่วประเทศ” (ตั้งค่าได้)
- ช่อง: ชื่อผู้ใช้, รหัสผ่าน, ☐ จดจำการเข้าสู่ระบบ (ติ๊ก = cookie อยู่รอดหลังปิด browser · ทั้งสองแบบหมดอายุเมื่อไม่ใช้งาน 30 นาที — BR-AU-03)
- ผิด → “ชื่อผู้ใช้หรือรหัสผ่านไม่ถูกต้อง” · ลองถี่เกิน → “พยายามเข้าสู่ระบบบ่อยเกินไป กรุณารอสักครู่” · ถูกระงับ → “บัญชีนี้ถูกระงับการใช้งาน”
- ไม่มีลิงก์สมัครสมาชิก (Admin สร้างบัญชีให้)

### 3.2 รายการใบงาน (`/work-orders`)

```text
รายการใบงาน                                              [+ สร้างใบงาน]
┌──────────┬─────────────┬────────────┬──────────┬────────────┬────────────┬───────────────┬──────────────────┬──────────────────┬──────────┬────────┐
│ สถานะ    │ เลขที่       │ ผู้ว่าจ้าง   │ ผู้สั่งงาน │ สถานที่รับ   │ สถานที่ส่ง  │ รถ             │ รับงาน           │ ส่งงาน           │ ค่าขนส่ง │        │
├──────────┼─────────────┼────────────┼──────────┼────────────┼────────────┼───────────────┼──────────────────┼──────────────────┼──────────┼────────┤
│ เปิดใบงาน │ NP2569110002 │ บริษัท ก.   │ คุณ ข.   │ คลัง A     │ โรงงาน B   │ 6 ล้อ · 70-1234 │ 26/11/2569 08:30 │ 26/11/2569 15:00 │ 3,500.00 │ ดู ⋯   │
│          │             │            │          │            │            │ + อีก 1 คัน     │                  │                  │          │        │
└──────────┴─────────────┴────────────┴──────────┴────────────┴────────────┴───────────────┴──────────────────┴──────────────────┴──────────┴────────┘
                                                                          ‹ ก่อนหน้า   หน้า 1 / 3   ถัดไป ›
```

- **1 แถวต่อใบงาน** (Q15) — คอลัมน์ “รถ” แสดงคันแรก + จำนวนคันที่เหลือ
- เรียงใหม่→เก่า หน้าละ 50 · `?page=` ที่ผิดรูปแบบกลับไปหน้า 1 (ระบบเดิม error)
- เมนู ⋯ ต่อแถว: ดู · แก้ไข (Maker, Admin) · พิมพ์ใบสั่งปฏิบัติงาน (แท็บใหม่) · ยกเลิกใบงาน · ลบใบงาน (Maker, Admin — ยืนยันก่อน)
- ใบงานที่ยกเลิกยังแสดงในรายการ ป้ายสถานะสีเทา · ใบงานที่ลบไม่แสดง (ADR-0010 ส่วนเพิ่มเติม)
- วันเวลาแสดงแบบ `dd/MM/yyyy HH:mm` ปี พ.ศ. · เงิน `#,##0.00`
- **ค้นหา (WO-16, ผู้ใช้ขอ 2026-11-27):** เลขที่ · สถานะ · ผู้ว่าจ้าง · ผู้สั่งงาน · สถานที่รับ · สถานที่ส่ง · รถ (ทะเบียน/ประเภท) · ค่าขนส่ง ตั้งแต่–ถึง · วันที่รับงาน และวันที่ส่งงาน เป็นปฏิทินเลือกช่วง (ปี พ.ศ., นับทั้งวันตามเวลาไทย) · ข้อความค้นหาแบบ “มีคำนี้อยู่” · เงื่อนไขอยู่ใน URL (แบ่งหน้า, Export และปุ่มย้อนกลับใช้ชุดเดียวกัน)
- **ติ๊กช่องหน้าแถว:** แถบด้านบนแสดง “เลือก n ใบ” + แก้ไข (เลือก 1 ใบ ไปหน้าแก้ไข) · พิมพ์ (1 ใบ) · ลบ (หลายใบได้) · ล้างการเลือก · ช่องหัวตาราง = เลือกทั้งหน้า
- **Export Excel:** ทุกใบที่ตรงกับการค้นหา (ไม่ใช่แค่หน้าที่เห็น) สูงสุด 10,000 ใบ · ชีต “ใบงาน” ทุกช่องของใบงาน 1 แถวต่อใบ · ชีต “รถในใบงาน” 1 แถวต่อรถ · วันที่และเงินเป็นค่าตัวเลขของ Excel
- หลัง MVP: คอลัมน์ Remark (WO-21)

- **แก้ไข** (`/work-orders/[id]/edit`, D26): ฟอร์มเดียวกัน เติมค่าเดิม · เปลี่ยนได้ทุกช่องรวมสถานะ (ยกเว้น “ยกเลิก”) · เลขที่ไม่เปลี่ยน · ถ้ามีคนบันทึกใบเดียวกันหลังเราเปิดฟอร์ม จะบันทึกไม่ได้และขอให้เปิดใหม่ · ข้อมูลพื้นฐานที่ถูกปิดใช้งานหลังสร้างใบงานยังเลือกค้างไว้ได้ (มีคำว่า “(ปิดใช้งาน)”)

### 3.4 ดูใบงาน (`/work-orders/[id]`)

- หัว: เลขที่ใบงาน · ป้ายสถานะ · สร้างโดย/เมื่อ · ถ้ายกเลิก: ยกเลิกโดย/เมื่อ
- เนื้อหา 5 ส่วนเหมือนฟอร์มแต่เป็นข้อความอ่านอย่างเดียว · **ไม่มีปุ่มบันทึก** (แก้ F2)
- ปุ่ม: พิมพ์ใบสั่งปฏิบัติงาน (แท็บใหม่) · ยกเลิกใบงาน (Maker, Admin — กล่องยืนยัน “ยกเลิกใบงาน NP… ใช่หรือไม่? ยกเลิกแล้วกลับคืนไม่ได้”) · สร้างใบงานใหม่
- การยกเลิก = เปลี่ยนสถานะเป็น 2 “ยกเลิก” + บันทึกผู้ยกเลิกและเวลา (ไม่ลบข้อมูล — ADR-0010)

### 3.5 ใบสั่งปฏิบัติงาน (`/work-orders/[id]/print`)

### 3.6 ข้อมูลพื้นฐาน (`/master/*`) — รูปแบบเดียวกันทั้ง 4 หน้า

```text
ผู้ว่าจ้าง                                   [ค้นหา…        ]  ☐ แสดงที่ปิดใช้งาน   [+ เพิ่ม]
┌──────────────────┬──────────────────────┬─────────────┬─────────────────┬──────────┬──────┐
│ ชื่อบริษัท          │ ที่อยู่                 │ เบอร์โทร     │ เลขผู้เสียภาษี    │ สถานะ    │      │
│ บริษัท ตัวอย่าง จำกัด │ 99 ถนนตัวอย่าง …      │ 02-xxx-xxxx │ 0-1055-xxxxx-xx-x │ ใช้งาน   │ ⋯   │
└──────────────────┴──────────────────────┴─────────────┴─────────────────┴──────────┴──────┘
⋯ = แก้ไข · ปิดใช้งาน / เปิดใช้งาน · ลบ (เฉพาะรายการที่ยังไม่ถูกใช้ในใบงาน)
```

- เพิ่ม/แก้ไขในกล่อง dialog · ข้อความ error ภาษาไทยใต้ช่อง · บันทึกสำเร็จแสดง toast
- **ปิดใช้งานแทนการลบ** (ค่าเริ่มต้น Q19 ที่ยืนยันแล้ว → MD-08 เข้ามาใน MVP แทนปุ่มลบเดิม): รายการที่ปิดใช้งานไม่อยู่ใน dropdown ของใบงานใหม่ แต่ใบงานเก่ายังแสดงชื่อเดิม · ลบถาวรได้เฉพาะรายการที่ยังไม่มีใบงานอ้างถึง (ฐานข้อมูลมี FK กันไว้)
- แก้ไขแล้วข้อมูลช่องอื่นไม่หาย (แก้ F7)

| หน้า | ช่อง (* = บังคับ) | กฎเพิ่มเติม | เรียงตาม |
|---|---|---|---|
| ผู้ว่าจ้าง | ชื่อบริษัท*, ที่อยู่*, เบอร์โทรศัพท์*, เลขประจำตัวผู้เสียภาษี* | เลขผู้เสียภาษี 13 หลัก (Should) | ชื่อ |
| รถ | ทะเบียน*, ประเภทรถ* | ทะเบียนไม่ซ้ำ | ทะเบียน |
| พนักงานขับรถ | ชื่อ*, นามสกุล*, เบอร์โทร | — | ชื่อ, นามสกุล |
| สถานที่รับ-ส่ง | สถานที่รับ*, สถานที่ส่ง*, ประเภทรถ*, ราคาขนส่งตามราคาน้ำมัน* (D38) | ราคาน้ำมัน 25–50 บาท ทีละ 1 (dropdown) + ราคา ≥ 0 ทศนิยม 2 ตำแหน่ง (พิมพ์เอง) แล้วกด + · อย่างน้อย 1 ราคา ราคาน้ำมันละ 1 ราคา · แก้/ลบแต่ละราคาในรายการ · ราคาที่กรอกค้างยังไม่กด + บันทึกไม่ได้ · ช่องสถานที่แนะนำชื่อที่มีอยู่ · เส้นทางเดิมแสดง “ราคาเดิม” จนกว่าจะแก้ | ใหม่→เก่า · ตารางแสดงช่วงราคาและจำนวนราคา |

### 3.7 จัดการผู้ใช้ (`/admin/users`) — Admin

- รายการ: ชื่อผู้ใช้, ชื่อ-นามสกุล, เบอร์, บทบาท, สถานะ (ใช้งาน / ระงับ)
- สร้างผู้ใช้: ชื่อผู้ใช้* (a–z, 0–9, `_` `.` ยาว 3–30 ตัว ไม่สนตัวพิมพ์), ชื่อ-นามสกุล*, เบอร์โทร, บทบาท* (Admin / Maker / Accounting), รหัสผ่านเริ่มต้น* (นโยบายใน Design 01 หัวข้อ 6)
- ต่อผู้ใช้: เปลี่ยนบทบาท · ตั้งรหัสผ่านใหม่ · ระงับ / เลิกระงับ (ระงับแล้ว session ทั้งหมดถูกเพิกถอน)
- กันพลาด: ระงับหรือลดบทบาท Admin คนสุดท้ายไม่ได้ · Admin ระงับตัวเองไม่ได้

## 4. รูปแบบ UI ที่ใช้ร่วมกัน

| เรื่อง | รูปแบบ |
|---|---|
| ฟอร์ม | react-hook-form + Zod schema เดียวกับ server · error ภาษาไทยใต้ช่อง · ปุ่มบันทึกแสดงสถานะกำลังบันทึก |
| เลือกจากรายการยาว | Combobox พิมพ์ค้นหาได้ (แทน Select2) |
| วันเวลา | ปฏิทิน + เวลา 24 ชม. แสดงปี พ.ศ. (ADR-0008) |
| การยืนยัน | AlertDialog ของ UI (แทน `confirm()` ของ browser) |
| กล่อง dialog | ปิดได้เฉพาะปุ่มยกเลิก/ปิด หรือ X — คลิกนอกกล่องหรือกด Esc ไม่ปิด ข้อมูลที่กรอกจึงไม่หายโดยไม่ตั้งใจ (ผู้ใช้ขอ 2026-11-27, D25) |
| ผลการทำงาน | toast สำเร็จ/ผิดพลาด · ไม่แสดง error ภายในของระบบให้ผู้ใช้ |
| ตาราง | หัวตารางติดบน · แบ่งหน้า · สถานะว่างมีข้อความ “ยังไม่มีข้อมูล” |
| ภาษา/รูปแบบ | ข้อความไทยทั้งหมด · วันที่ `dd/MM/yyyy` พ.ศ. · เวลา `HH:mm` · เงิน `#,##0.00` |
| สี/แบรนด์ | สีหลักน้ำเงินจากโลโก้ NP Pool · สีเน้นเหลืองแบบหัวกล่องในใบพิมพ์เดิม (ADR-0006) |
